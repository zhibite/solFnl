📡 对外 API 文档

供第三方系统集成调用（无需登录）

① 基础地址：所有路径都挂在 http://<主机>:8038 之下（端口由环境变量 PORT 决定，默认 8038）。

② 鉴权：这一组接口全部开放，不需要登录、不要带 Cookie 或 token，直接请求即可。

③ 请求格式：POST 接口必须带请求头 Content-Type: application/json，请求体是一个 JSON 对象；GET 接口用 query 参数传月份。

④ 返回格式：统一返回 JSON，其中 success 是布尔值表示成败。失败时 HTTP 状态码仍是 200，请在 message 字段里读具体原因，不要只看状态码。

⑤ 分页：GET /api/wallets 和 GET /api/profit 默认/最多返回 100 个钱包/页，用 limit + offset 翻页，响应带 pagination。

方法 端点 用途 请求参数
POST /api/wallets 只把地址登记进跟踪列表，不抓取任何数据。适合先批量收地址、之后再统一同步；地址已存在时只更新非空 label，并保留原有启用状态 body: address (必填) · label (可选)
POST /api/track 登记地址并立即抓取历史数据入库，返回抓取结果和可分享的盈利页地址。抓取耗时较长 body: address (必填) · label (可选) · months (可选, 如 ["2026-10"])
GET /api/wallets 分页列出跟踪地址及 label、meta、score；默认/最多 100 个/页 query: limit (可选, 默认/最大 100) · offset (可选)
GET /api/profit?month=2026-10 分页列出已启用地址该月汇总（含 meta/score），total_pnl 是所有启用地址的合计；默认/最多 100 个/页 query: month · limit (默认/最大 100) · offset
GET /api/profit/<address> 单个地址的每日明细，days[] 按天给买入/卖出、转入/转出的笔数与金额、胜负单数和已实现盈亏，外加 summary、meta、score。默认实时刷新 meta（60 秒缓存），传 refresh=0 可跳过 path: <address> · query: month (可选) · refresh (可选, 默认 1)
GET /profit/<address>?month=2026-10 同一份数据的网页版，直接在浏览器打开即可查看图表，并可把链接分享给别人 path: <address> · query: month (可选)
GET /api/health 健康检查，返回 {"success": true, "service": "gmgndaily"}，可用于探活 无

📌 请求参数详解（两个 POST 接口通用）

  • address （必填） — Solana 地址，base58 编码、32–44 个字符。缺失或为空报 address required，格式不对报 invalid solana address。
  • label （可选） — 这个地址的备注名，例如「聪明钱01」，会显示在网页和汇总里。不传则保留已有备注（新地址为空）。
  • months （仅 /api/track，可选） — 要抓哪几个月，数组，元素形如 "2026-10"。不传则按系统配置抓当月 + 往前 N 个月。

🧪 调用示例（curl）

# 1) 登记地址，不抓数据
curl -X POST http://127.0.0.1:8038/api/wallets \
  -H "Content-Type: application/json" \
  -d '{"address":"Gavtn1EfSV7s3xvUoZruDCnyoVU94WT2KA7WSnAzdxzN","label":"聪明钱01"}'

# 2) 登记地址 + 立即抓取入库
curl -X POST http://127.0.0.1:8038/api/track \
  -H "Content-Type: application/json" \
  -d '{"address":"Gavtn1EfSV7s3xvUoZruDCnyoVU94WT2KA7WSnAzdxzN","label":"聪明钱01","months":["2026-10"]}'

# 3) 查看地址列表
curl "http://127.0.0.1:8038/api/wallets?limit=100&offset=0"

# 4) 地址当月汇总（分页） / 单地址每日明细
curl "http://127.0.0.1:8038/api/profit?month=2026-10&limit=100&offset=0"
curl "http://127.0.0.1:8038/api/profit/Gavtn1EfSV7s3xvUoZruDCnyoVU94WT2KA7WSnAzdxzN?month=2026-10"

# 5) 健康检查
curl http://127.0.0.1:8038/api/health

📤 返回示例

  • POST /api/wallets → {"success": true, "wallet": {"address": "...", "label": "...", "enabled": 1, "created_at": "...", "updated_at": "..."}}
  • POST /api/track → {"success": true, "wallet": "...", "added": true, "months": ["2026-10"], "results": [{"month": "2026-10", "days": 21, "pnl": 123.4, "source": "gmgn"}], "summary": {...}, "profit_url": "/profit/...?month=2026-10"}，其中 added 表示这次是不是新加的地址，results 是每月抓取结果。全部月份失败时 success 为 false。
  • GET /api/profit → {"success": true, "month": "2026-10", "total_pnl": 1234.5, "wallets": [...]}
  • GET /api/profit/<address> → {"success": true, "wallet": "...", "month": "2026-10", "summary": {...}, "days": [...]}，days[] 每项对应一天的记录。

⚠️ 常见错误（success 为 false，看 message）

  • address required — body 里没有 address 或值为空。
  • invalid solana address — 地址不是合法的 Solana 地址（长度或字符集不对）。
  • body must be JSON — 没带 Content-Type: application/json，或 body 不是合法 JSON。
  • months must be a list of YYYY-MM strings — months 不是数组，或元素不是合法的 YYYY-MM；省略或传 [] 时按默认月份处理。
  • wallet saved but sync failed: ... — 地址已经存进去了，只是这次抓取失败，可稍后重新调用 /api/track 或等定时任务重试。

💡 怎么选：只想批量加地址选 /api/wallets（瞬间返回）；想加完马上拿到数据选 /api/track（会等待抓取完成）。拿到数据后用 /api/profit 系列读结果。
